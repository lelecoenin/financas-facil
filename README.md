# 💰 Finanças Fácil

Sistema de controle financeiro desenvolvido por Thayamy.

## Funcionalidades

- Dashboard financeiro
- Receitas e despesas
- Histórico de transações
- Gráficos interativos
- Metas financeiras
- Calculadora de investimentos
- Tema escuro
- Salvamento automático no navegador

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Chart.js
